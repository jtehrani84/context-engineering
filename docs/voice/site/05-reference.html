    Check Catalog

    Text Normalization

    Every scan reads canonical text from text-normalize.mjs, so a tell cannot be hidden by typing it with invisible or look-alike characters. Its exports:

    ExportDoes
    canonicalForScannormalizeForScan, then stripEmphasis. The CLI prints this.
    normalizationStatsCounts of zero-width, bidi, other invisible and look-alike characters, for the report.
    normalizeForDetectorThe lighter form the detector gets, since it counts some of these characters itself.
    normalizeForScanUnicode canonical form for the overlay and the injection check: hidden characters removed, NFKC, look-alike letters folded, quote, dash and space variants unified.
    renderedViewThe text as a reader sees it: markup rendered, entities decoded, combining marks and look-alikes folded.
    revealTagsDecode Unicode tag characters (U+E0000 block) into the ASCII they spell.
    stripEmphasisRemove markdown and inline-HTML emphasis markers so they cannot split a phrase.
    stripHiddenRemove invisible characters: zero-width, bidi, tag, variation selectors and other format characters.

    Judge Panel

    No juror shares the vendor of the drafter named with --drafter. With the default drafter, unknown, no vendor is excluded, so an undeclared draft can be judged by its own lab. The registry holds 4 judges. With the default consensus panel, the panel for each drafter vendor is the first two neutral jurors in a fixed order, the rest are spares asked only when a juror errors, and a lone surviving juror cannot reject. With --judge <name>, that one judge is the panel and its answer alone decides the judge layer. A judge reply without a clockable YES or NO and a numeric ai_ness counts as a failed juror, never as a vote.

    Hook Tiers and Matchers

    voice-tell-gate.py runs on tool calls, never on conversation text. It has two tiers, matched to whether the action can be undone. It keys on the raw detector score, not adjustedScore, and calls no judge.

    EventMatcherTier
    PostToolUseWrite|Edit|MultiEditNUDGE: a file write is never blocked
    PreToolUsethe send tools belowBLOCK or NUDGE

    A send tool name is matched as a substring of the tool name, so one entry covers every MCP server prefix (31 names): slack_send_message, slack_send_message_draft, slack_schedule_message, slack_create_canvas, slack_update_canvas, send_gmail_message, draft_gmail_message, create_doc, import_to_google_doc, batch_update_doc, insert_doc_elements, modify_doc_text, find_and_replace_doc, update_doc_headers_footers, create_presentation, import_to_google_slides, batch_update_presentation, create_form, batch_update_form, manage_document_comment, manage_presentation_comment, manage_spreadsheet_comment, create_pull_request, create_issue, add_issue_comment, create_pull_request_review, update_pull_request, update_issue, add_comment_to_pending_review, add_reply_to_pull_request_comment, pull_request_review_write.

    A tool whose own name (the part after the last __) has any of read, search, list, get, fetch, download, poll, branch as a whole word is never treated as a send, so list_spreadsheet_comments is a read and manage_spreadsheet_comment is a send.

    File writes are checked only for .html, .htm, .md, .mdx, .txt, .rtf, .docx files, and only when the text written (the content, the edit's new text, or a MultiEdit's new texts joined) is at least 400 characters. A send is checked when its harvested prose is at least 3 characters; keys that hold plumbing (channel, id, url, path and 26 others) are skipped.

    SurfaceOutcomeTrigger
    SendBLOCKA critical-severity overlay structure (<prefix>-struct-*, any issue prefix); an overlay phrase (<prefix>-phrase) the overlay marks critical or the lexicon blocks; a lexicon block word or block phrase; the scorer or normalizer failing, timing out or returning unusable output
    SendNUDGEA high or medium overlay structure; a lexicon nudge word; any other overlay phrase the lexicon does not exempt; raw score at or above 40 on text longer than 200 characters
    File writeNUDGEAny flagged item, or raw score at or above 40. A scorer failure adds a visible warning that the structure checks did not run

    Timeouts: the scorer gets 20 seconds by default (VOICE_SCORER_TIMEOUT, valid range above 0 up to 40); the normalizer gets the smaller of that and 10 seconds.

    The hook does not read overlay word hits (<prefix>-word) or cadence and register checks (<prefix>-cadence-*); those show in the scorer's and the gate's output only.

    Lexicon

    The hook carries its own word and phrase list, the lexicon, because the generic detector scores single slop words near 0 on short text, which is the send surface. Overlay word hits are ignored in favor of it. The tiers are block words, block phrases, nudge words and never-flagged words; edit them in your copy of the hook.
